# Lee Toolbox

Lee Toolbox 是一个可扩展的本地工具箱。

> 本项目由 AI 生成和迭代，仅供学习使用，不用于商业用途。

## 页面使用

- **查找工具** 在「全部工具」搜索名称或关键词，也可以从侧栏按分类浏览。找到后点击「打开工具」。
- **收藏工具** 点击工具卡片的星标，在「我的收藏」中查看。再次点击星标可取消收藏。
- **最近使用** 从侧栏的「最近使用」打开之前访问过的工具。
- **任务中心** 查看后台任务进度，完成后下载结果。

## 本地运行指南

需要 Python 3.11+ 和 Node.js 22.12+（含 npm）。首次运行时，在项目根目录执行以下命令。

```bash
./scripts/setup.sh
./scripts/build.sh
./scripts/start.sh
```

启动后打开[本地工具箱](http://127.0.0.1:8000)，按 `Ctrl+C` 停止。

- **日常启动**运行 `./scripts/start.sh`。
- **开发调试**运行 `./scripts/dev.sh`，打开[开发页面](http://127.0.0.1:5173)。
- **运行测试**执行 `./scripts/test.sh`。
